BookShelf for PRM393 — QE190009, Hồ Lê Quốc Khánh.

Android app with Firebase Email/Password authentication, a private book library,
validated add/edit forms, favorites, combined search/filters, live summary and
confirmed deletion. The APK connects to the student's Firebase project using
public client configuration. Install on Android 7.0 or newer.

Source code and `firestore.rules` are available in this repository.
